
### 🤖 Gemini Clone - AI Assistant

A responsive React-based clone of Google's Gemini AI interface, featuring modern design and mobile optimization.

![Gemini Clone Preview](https://img.shields.io/badge/React-18.0+-blue.svg)
![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features

- 🎨 **Modern UI Design** - Clean, responsive interface inspired by Google Gemini
- 📱 **Mobile Responsive** - Optimized for all screen sizes
- 🚀 **Fast Performance** - Built with React and Vite
- 💬 **Interactive Chat** - Real-time conversation interface
- 🎭 **Smooth Animations** - CSS animations and transitions
- 🌙 **Dark Theme** - Elegant dark mode design
- 📝 **Code Syntax Highlighting** - Proper formatting for code responses
- 🔍 **Search Suggestions** - Quick prompt cards for easy interaction

## 🛠️ Tech Stack

- **Frontend**: React 18+
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + Custom CSS
- **Icons**: Remix Icons
- **State Management**: React Context API
- **Language**: JavaScript (ES6+)

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ 
- npm or yarn

## Live Link
   (https://gemini-clone-2025.netlify.app/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sohrabansari990/Gemini_clone.git
   cd Gemini_clone
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:5173
   ```
